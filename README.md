# Веб-каталог квіткового магазину з Telegram-ботом

## 1. Опис проєкту
зручний веб-каталог для швидкого підбору букетів без реєстрації. Заявка відправляється в пару кліків прямо флористу в Telegram.

## 2. Мета та цільова аудиторія
* **Мета:** Створити легкий каталог із фільтрацією та формою швидкого замовлення.
* **Цільова аудиторія:** Покупці квітів та флористи магазину.

## 3. Ролі користувачів
* **Клієнт Гість:** Переглядає каталог, фільтрує товари, залишає ім'я та телефон у формі замовлення.
* **Флорист Працівник:** Отримує сповіщення про нові заявки в Telegram-бот та обробляє їх.

## 4. Основні функції
* Каталог букетів із фільтрацією за ціною та категоріями.
* Картка товару з описом та фото.
* Модальне вікно швидкого замовлення.
* Інтеграція з Telegram API для сповіщень.
