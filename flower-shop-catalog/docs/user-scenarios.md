\# Bloomify — Веб-каталог квіткового магазину з Telegram-ботом



\## 1. Назва та опис проєкту

Bloomify — це зручний веб-каталог для перегляду та швидкого підбору квіткових композицій. Завдяки відсутності реєстрації клієнт може оформити заявку в пару кліків, після чого сповіщення з деталями замовлення миттєво надходить флористу в Telegram-бот.



\## 2. Проблема, мета та цільова аудиторія

\* \*\*Проблема:\*\* Складність швидкого підбору букетів у соцмережах та відсутність потреби проходити довгу реєстрацію на сайті ради одного замовлення.

\* \*\*Мета:\*\* Створити легкий каталог із фільтрацією та формою швидкого замовлення, яка автоматично надсилає сповіщення у Telegram-бот флориста.

\* \*\*Цільова аудиторія:\*\* Покупці, яким потрібно швидко обрати букет і залишити контактний номер, а також флористи магазину.



\## 3. Ролі користувачів

\* \*\*Клієнт (Відвідувач):\*\* Переглядає каталог, фільтрує букети за ціною та складом, заповнює форму швидкої заявки (ім'я та телефон) без створення акаунта.

\* \*\*Працівник (Флорист):\*\* Отримує сповіщення про нові заявки через Telegram-бот та зв'язується з покупцем для підтвердження.



\## 4. Основні функції та сторінки

\* \*\*Головна сторінка / Каталог:\*\* Перегляд списку квітів із можливістю пошуку, сортування та фільтрації.

\* \*\*Картка товару:\*\* Детальна інформація про склад букета, ціну, наявність та якісні фотографії.

\* \*\*Форма швидкої заявки:\*\* Модальне вікно для введення імені й телефону з валідацією.

\* \*\*Інтеграція з Telegram API:\*\* Автоматична відправка замовлень у робочий чат магазину.



\## 5. Склад команди та відповідальність

\* \*\*Олєйнікова Дар'я\*\* — Fullstack Developer (проектування бази даних та UI, розробка каталогу, підключення Telegram Bot API, налаштування Git-репозиторію).



\## 6. Заплановані технології

\* \*\*Frontend:\*\* HTML5, CSS3, JavaScript (ES6+)

\* \*\*Backend / API:\*\* Node.js, Telegram Bot API

\* \*\*Tools \& VCS:\*\* Git, GitHub, Trello, Visual Studio Code



\## 7. Поточний статус проєкту

Етап проектування: розроблено технічне завдання, UML-діаграми (Use Case, Class, Sequence, Activity), створено дошку в Trello та сформовано початкову структуру Git-репозиторію.
